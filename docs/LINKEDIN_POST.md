# LinkedIn Post: University of Waterloo Elective Chooser

## 🎓 Just built something I'm really excited about!

I've been working on an **AI-powered elective recommendation system** specifically designed for University of Waterloo Engineering students, and I wanted to share what makes this project special.

## 🚀 What it does:
- **Personalized Course Recommendations**: AI analyzes your program, interests, and career goals to suggest the perfect electives
- **Natural Language Chat Interface**: Ask questions like "What courses should I take for machine learning?" and get intelligent responses
- **Comprehensive Database**: 284+ courses from all 11 Waterloo Engineering programs with detailed information
- **Smart Search**: Find courses by skills, workload, department, or any criteria that matters to you

## 🛠️ Tech Stack Highlights:
**Frontend**: Next.js 15, TypeScript, Tailwind CSS
**Backend**: Python, Supabase (PostgreSQL), pgvector for vector search
**AI/ML**: OpenAI GPT-4o-mini, LangChain, RAG (Retrieval Augmented Generation)
**Data Processing**: Pandas, BeautifulSoup, automated web scraping

## 💡 Key Features:
✅ **Vector Search**: Semantic search through course descriptions
✅ **User Profiles**: Personalized recommendations based on your academic program
✅ **Admin Interface**: Easy data management and updates
✅ **Responsive Design**: Works perfectly on desktop and mobile
✅ **Dark Mode**: Because we all code in the dark 😄

## 🎯 The Problem it Solves:
Choosing electives can be overwhelming - there are hundreds of courses, complex prerequisites, and it's hard to know which ones align with your career goals. This tool makes that decision process intelligent and personalized.

## 🔧 Technical Deep Dive:
- **RAG Implementation**: Combines course data with AI for context-aware responses
- **Vector Embeddings**: Uses OpenAI's text-embedding-3-large for semantic search
- **Database Design**: Optimized PostgreSQL schema with JSONB for flexible queries
- **Memory Management**: LangChain handles conversation context across sessions
